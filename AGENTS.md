# CadKit preferences

## Application copy

CadKit is a professional application for professionals. Use almost no UI copy.
Prefer short functional labels, usually one word: Projects, Open, New, Save.
Do not add slogans, cutesy phrasing, welcome messages, promotional language,
onboarding prose, or descriptions that repeat an obvious action. Keep explanation
only when needed to make a decision, prevent a mistake, or resolve an error.
Keep accessible labels descriptive enough to identify controls and their targets.
