# How-to guides

Choose a guide when you already have a model and want to complete a particular
task. If this is your first CadKit project, start with the
[box and lid tutorial](../tutorials/index.md).

| I want to… | Guide |
| --- | --- |
| Install CadKit or open my project | [Install and open a project](install.md) |
| Keep my existing CadQuery builders | [Adopt an existing model](adopt-cadquery.md) |
| Produce manufacturing files and inspect failures | [Export parts and run checks](export-and-check.md) |
| Choose hole dimensions and test a printed fit | [Use catalogue fasteners and fit coupons](fasteners-and-fit.md) |
| Inspect clearances in the desktop app | [Inspect and measure an assembly](inspect-and-measure.md) |
| Let an agent see the model I am looking at | [Connect an agent](connect-an-agent.md) |
| Estimate material and print time | [Slice a build](slice-parts.md) |
| Reuse a moving subassembly | [Nest assemblies and name poses](nested-assemblies.md) |
| Make a rendered image | [Render with Blender](render-with-blender.md) |
